This image-processing experiment compares global thresholding alone with dilation, erosion, opening, and closing on a rice-grain image. The processing algorithms are implemented manually in Python and run in Google Colab.

## Run the experiment in Google Colab
1. Open Untitled0.ipynb in Google Colab.
2. Run the cells from top to bottom.
3. When prompted, upload one rice-grain image or another image with bright objects on a dark background.
4. Inspect the original image and global thresholding result.
5. Run the remaining cells to display dilation, erosion, opening, and closing separately.

The notebook imports Pillow, NumPy, and Matplotlib.
